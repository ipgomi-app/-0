# (카톡/메일 발송용) 입고미회수 전산개선 요청 — 의견 조회

> 8/7 조헌영 본부장님 전달 예정 건. 각 권역 의견 취합용 축약본.

---

**입고미회수 전산개선 요청 건으로, 아래 내용 외에 추가 개선 요청이 있으시면 조언 부탁드립니다.**
(8월 7일경 조헌영 본부장님께 입고미회수 관련 전산개선 내용 전달 예정 / 기존 테스트 화면 첨부)

■ **배경**
부산권역 입고미회수 실적 저조 원인 파악을 위해 담당자–차량기사 면담 및 현장 동행 방문을 실시했고,
아래 2가지가 확인되었습니다.
1. 자산관리 등 일부를 제외한 대부분의 기사는 기존 실물회수 업무에 집중하여, **사전 확인이 안 된 업체는 방문하지 않음**
2. 담당자는 종이 출력물 전달 여부가 제각각이고, 카톡·유선으로 전달한 후 **사후 이행 여부를 확인하지 않음**

즉, **확인한 정보(담당자)와 실제 회수(기사) 사이에 시스템 연결이 없는 것**이 핵심 원인으로 판단됩니다.

■ **부산권역 입고미회수 개선 제안 예정 내용 (3건)**

**1) 기사–담당자 간 업체 확인내용 상호 공유**
　- 원인 사유 선택(9~11종) + 추가 메모 방식으로 상호 정보 공유
　→ 매일 전화하고, 카톡 보내고, 잊어버리고, 또 연락하고, 확인하는 **반복 루프** 발생 중
　→ **로지스올앱 ↔ 스마트랜스 연결**로 내용 확인 후 처리 효율 향상
　　(데이터 처리 = 담당자 / 실물 회수 = 기사, 역할은 분리하되 정보는 공유)

**2) 담당자·영업지원이 확인한 업체는 스마트랜스에 별도 표기**
　→ 확인 완료 업체를 색상·아이콘으로 구분 표시
　→ 기사 방문 시 **분쟁 없이 바로 실물 회수** 가능

**3) 스마트랜스에서 업체 클릭 시 입고내역이 한 번에 표시**
　→ 업체 방문 시 입고처 확인을 위해 **여러 번의 조작이 필요**하여 불편
　→ 현장에서 즉답 가능 → 회수 거부·분쟁 감소

■ **참고**
- 위 항목은 **기존 스마트랜스에 이미 구현된 기능 범위** 내의 확장이며, 신규 기능 개발이 아닙니다.
- 스마트라토스에는 이미 `특이지점 > 입고미회수` 위치 표시와 `거리순/라우팅순` 기능이 있어,
  **“위치 표시”까지는 되어 있고 “확인내용 공유·확인완료 표기·입고내역 즉시조회”가 빠져 있는 상태**입니다.
- 부산권역에서 위 3건에 대한 **사전 검증(테스트)을 완료**하였으며, 화면 자료 첨부 가능합니다.

■ **추가로 검토 요청드리고 싶은 항목** (의견 주시면 반영하겠습니다)
- 처리 즉시 전 사용자 목록 반영(중복 방문·중복 연락 차단)
- 음영지역 오프라인 입력 후 통신 복구 시 자동 전송
- ‘다음에 회수협의’ 건 예정일 등록 → 해당일 자동 재노출
- 사유별·담당자별·지점별 처리 통계 자동 산출
- 처리 결과의 업무일지 자동 연계(이중 입력 제거)
